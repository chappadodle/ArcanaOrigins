# Arcana Origins

Elemental magic as Origins, for [NeoOrigins](https://modrinth.com/mod/neo-origins) on NeoForge 1.21.1.

Pick an element as your origin and you simply have its magic: three spells on your skill keys,
passives and a weakness. No mana, no levels, no items. The spells come from
[Elemental Arcana](https://github.com/chappadodle/ElementalArcana).

Work in progress: see `docs/superpowers/specs/2026-10-09-arcana-origins-design.md` for the plan.
